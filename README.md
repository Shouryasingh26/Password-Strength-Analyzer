
# Password Strength Analyzer

## Project Description
Password Strength Analyzer is a Python-based web application
that evaluates the strength of user-entered passwords.

It checks password length, uppercase letters, lowercase
letters, numbers and special characters.

## Objectives
- Analyze password strength.
- Identify password weaknesses.
- Provide suggestions for stronger passwords.
- Generate secure random passwords.
- Promote password security awareness.

## Features
- Password strength detection.
- Show/Hide password.
- Security checklist.
- Password improvement suggestions.
- Strong password generator.
- Interactive progress bar.

## Technologies Used
- Python
- Streamlit
- Regular Expressions (re)
- Secrets Module
- HTML and CSS (through Streamlit styling)

## Installation

1. Clone the repository.
2. Open the project folder.
3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   python -m streamlit run app.py
